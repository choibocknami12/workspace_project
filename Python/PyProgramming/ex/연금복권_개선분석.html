🎟️ 연금복권 번호 생성기 개선 분석

기존 과제_연금복권_수정.py 를 분석하고 개선하여 과제_연금복권_개선.py 로 새로 작성한 내용을 정리한 문서입니다.

1. 기존 코드

import random

numFirst = random.randint(1, 5)
numbers = []

for i in range(100):
    numSec = random.randint(0, 9)

    if numSec not in numbers:   # ← 중복 숫자를 막음
        numbers.append(numSec)

    if len(numbers) == 6:
        break

print(f"{numFirst}조", numbers)

실행 결과 예시: 3조 [1, 4, 7, 2, 9, 3]

2. 발견한 문제점

🔴 핵심 문제 — 복권 규칙과 다름

실제 연금복권720+ 는 6자리 번호의 각 자리가 서로 독립적이며 0~9 사이에서 중복이 허용됩니다. (예: 632888 가능)

그러나 기존 코드는 if numSec not in numbers 로 이미 나온 숫자를 버려서 항상 서로 다른 6개 숫자만 생성됩니다. 즉 실제 복권에서 나올 수 있는 번호의 상당수를 만들 수 없습니다.

구분문제 설명영향
규칙 오류 not in 검사로 중복 숫자 제거 실제 복권 번호(예 112233)를 만들지 못함
불안정한 반복 range(100) 안에서 break 로 6개를 채우는 구조 의도가 불명확하고, 조건이 바뀌면 깨지기 쉬움
출력 형식 파이썬 리스트 [1, 4, 7, 2, 9, 3] 그대로 출력 복권 번호처럼 보이지 않음 (대괄호·쉼표·공백)
재사용 불가 함수 없이 한 번만 실행되는 스크립트 여러 장 생성·테스트·재사용이 어려움
매직 넘버 1, 5, 9, 6, 100 등 숫자가 코드에 직접 박힘 규칙 변경 시 일일이 찾아 고쳐야 함

3. 개선한 코드

import random

# 연금복권720+ 번호 생성기
# 구조: 1개의 '조'(1~5) + 6자리 번호(각 자리 0~9, 중복 허용)

GROUP_MIN, GROUP_MAX = 1, 5   # 조 범위
DIGIT_MIN, DIGIT_MAX = 0, 9   # 각 자리 숫자 범위
DIGIT_COUNT = 6               # 번호 자릿수


def generate_lotto():
    """연금복권 1장을 생성해 (조, 6자리숫자리스트) 튜플로 반환한다."""
    group = random.randint(GROUP_MIN, GROUP_MAX)
    # 각 자리는 서로 독립이며 중복이 가능하므로 not in 검사를 하지 않는다.
    numbers = [random.randint(DIGIT_MIN, DIGIT_MAX) for _ in range(DIGIT_COUNT)]
    return group, numbers


def format_lotto(group, numbers):
    """생성된 번호를 보기 좋은 문자열로 변환한다. 예) '3조 482917'"""
    digits = "".join(str(n) for n in numbers)
    return f"{group}조 {digits}"


def main(count=1):
    """count장 만큼 연금복권 번호를 출력한다."""
    for i in range(count):
        group, numbers = generate_lotto()
        print(f"[{i + 1}장] {format_lotto(group, numbers)}")


if __name__ == "__main__":
    main(5)   # 예시: 5장 생성

실행 결과 예시:

[1장] 5조 701287
[2장] 4조 406709
[3장] 2조 632888   ← 8이 중복되어도 정상
[4장] 4조 009031
[5장] 4조 763881

4. 개선 항목 정리

항목이전개선
규칙중복 허용 서로 다른 6개 숫자만 각 자리 0~9 독립 추출(중복 허용)
구조생성 방식 range(100)+break 리스트 컴프리헨션으로 6자리 한 번에
출력형식 [1, 4, 7, 2, 9, 3] 3조 147293 (복권 형태)
재사용함수화 단일 스크립트 generate / format / main 분리
확장여러 장 1장 고정 main(count) 로 N장 생성
유지보수상수화 매직 넘버 산재 상수로 분리해 한 곳에서 관리
안전실행 보호 import 시 즉시 실행 if __name__ == "__main__"
